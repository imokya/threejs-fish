# 深海鱼群 · three.js WebGPU

基于 three.js r186 `WebGPURenderer` + TSL 的实时水下鱼群模拟。

## 运行

```bash
npm install
npm run dev
```

然后用支持 WebGPU 的浏览器（Chrome / Edge 113+、Safari 18+）打开终端里显示的地址。

- 移动鼠标 / 手指划过：驱散鱼群（受惊状态会在鱼群中波状传播）
- 点击：在鱼群处产生冲击波
- 滚轮：拉近 / 拉远
- 右上角「画面调节」面板（按 H 隐藏）：实时调整鱼身亮度、光柱、泛光、梦幻程度、海水浑浊度、太阳高度、曝光；指定形态与镜头；「梦幻 / 清透 / 深邃」预设；「复制当前参数」可把调好的数值发给开发者固化为默认值（设置会记在本机浏览器里）
- `?n=4096`：自定义鱼的数量（默认桌面 6144、移动端 3072）

## 实现要点

| 模块 | 内容 |
| --- | --- |
| `src/boids.js` | GPU 计算着色器 Boids：GPU 空间网格（计数排序）邻居搜索；分离 / 对齐 / 聚合；鱼球、鱼龙卷、环形鱼阵、分群四种形态；指针射线驱散、恐慌传播 |
| `src/choreography.js` | 形态时间线（平滑过渡）与电影化镜头（远景环绕、贴边滑过、侧逆光、仰拍），按镜头调曝光 |
| `src/events.js` | 动态瞬间：自动受惊爆散再合拢、鱼流擦镜而过（镜头定格跟拍） |
| `src/panel.js` | 调节面板与预设 |
| `src/fish.js` | 程序化鱼模型，顶点着色器内按速度朝向、沿身体的行波摆尾（频率随速度变化），物理材质（金属银鳞 + 虹彩 + 清漆），背部焦散光斑 |
| `src/ocean.js` | 海水消光系数（红光衰减最快）、方向散射色、焦散与光柱图案 |
| `src/environment.js` | 海底沙丘、礁石、摇曳海藻、从下仰望的水面（斯涅尔窗 + 倒映海底的全反射 + 跳动碎光）、随洋流漂移的海洋雪、石缝气泡串、水下雾、环境反射贴图 |
| `src/post.js` | 光线步进体积光（Henyey-Greenstein 前向散射）+ 基于阴影贴图的体积阴影（鱼群遮挡光柱，半分辨率计算）、水下折射扭曲、随距离的散射柔化、色差、泛光、调色、暗角 |
